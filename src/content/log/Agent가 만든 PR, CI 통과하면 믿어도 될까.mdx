Agent가 생성한 PR, CI까지 모두 통과했다면 믿어도 될까?

AI Agent PR을 분석한 [논문](https://arxiv.org/abs/2607.18057)에 따르면 절반만 테스트를 함께 작성했고, 예외 처리 코드는 80% 이상 테스트되지 않는 경우가 많았다!

CI가 PASS됐다는 것이 변경 코드가 충분히 검증되었다고 하긴 어렵다. 리뷰 시 예외 케이스와 테스트 커버리지를 꼭 확인하자. 🤔
